## 👨‍💻 About Me

Backend-focused developer building automation systems for Discord communities and high-load environments. I turn ideas into products — API integrations, payment flows, Twitch services and Minecraft addons.

- 🔭 Currently building **Equicord-Themes**, **notvictornw-site** and **NieworldAPI**
- 🌱 Always learning — scalable architectures, frontend development and performance tuning
- ⚡ Philosophy: **Scale > Manual · Speed > Perfection · Systems > Ideas**
- 💬 Ask me about Discord automation, API integrations, CSS theming and developer tooling
